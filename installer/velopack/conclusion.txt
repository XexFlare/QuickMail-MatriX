MailBox MatriX has been installed.

You can start MailBox MatriX from the Start Menu. The first time it runs, MailBox MatriX offers to add a desktop shortcut; you can change that choice anytime in Settings.

On first launch, open Settings, then Accounts, to add your email account. Press F1 inside the app to open the user guide.

MailBox MatriX will keep itself up to date automatically from now on.
